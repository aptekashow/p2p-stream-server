# P2P Stream Server v0.3.0

P2P-каталог каналов и HLS relay для Ubuntu Server 24.04 с использованием локального Ace Stream Engine.

## Возможности

- Импорт M3U-каталога в SQLite.
- Поиск по названию канала без учёта регистра, включая кириллицу.
- Запуск Ace Stream playback по infohash.
- Выдача HLS через адрес приложения `/live/{id}/index.m3u8`.
- Проксирование MPEG-TS сегментов без перекодирования.
- Настраиваемая задержка воспроизведения: `DEFAULT_BUFFER_SECONDS` (по умолчанию 10 секунд).
- Плейлист `/playlist.m3u` со ссылками на каналы.
- Проверка доступности Ace Stream Engine через `/api/health`.

## Установка и запуск

1. Скопируйте `.env.example` в `.env`.
2. Укажите адрес локального Ace Stream Engine в `ACESTREAM_BASE_URL`.
3. Настройте `DEFAULT_BUFFER_SECONDS=10` или другое нужное значение.
4. Запустите: `docker compose up -d --build`.
5. Откройте `http://SERVER_IP:9999`.

В текущем Docker Compose используется host networking: приложение обращается к Engine через `127.0.0.1:6878`. Не публикуйте API Engine в Интернет.

## Буфер и хранение

Сервер непрерывно опрашивает HLS-плейлист Ace Stream, скачивает каждый новый завершённый сегмент и атомарно сохраняет его на диск без перекодирования. VLC получает отдельный HLS-плейлист, собранный только из уже сохранённых сегментов.

- Задержка от live edge задаётся через `DEFAULT_BUFFER_SECONDS` (10 секунд по умолчанию).
- Кольцевой дисковый кэш хранит сегменты не более `HLS_CACHE_SECONDS` (60 секунд).
- Плейлист VLC не рекламирует сегменты, которые ещё не скачаны или уже отсутствуют в кэше.
- Если загрузчик перестаёт получать новые сегменты, выполняется восстановление Ace Stream session; зависшая задача кэширования запускается повторно.
- Сегменты передаются VLC как есть, без перекодирования.

## Ограничения перед публичной эксплуатацией

- Авторизация и HTTPS перед публикацией веб-интерфейса в Интернет.
- Нагрузочное тестирование реального числа одновременных каналов на конкретном сервере.
- Проверка совместимости с зашифрованными HLS-потоками и fMP4; текущий relay рассчитан на обычные MPEG-TS HLS-сегменты.

Приложение не устанавливает искусственный лимит каналов; реальная одновременная нагрузка ограничена ресурсами сервера и доступностью P2P-источников. Используйте только потоки, которые вы вправе просматривать и ретранслировать.
